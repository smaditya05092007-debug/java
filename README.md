# 🎓 Student Management System — Java

A console-based Student Management System built in Java
using Object-Oriented Programming principles.

## Features
- Add Undergraduate & Graduate Students
- View all student records
- Search student by ID
- Delete student by ID

## Concepts Used
- Inheritance & Polymorphism
- Encapsulation (Service layer pattern)
- Scanner for user input
- Switch-case menu system

## How to Run
```bash
javac Main.java
java Main
